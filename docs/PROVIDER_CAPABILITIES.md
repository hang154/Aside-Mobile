# 실제 공급자 지원 범위

기준: 2026-10-31, Asia/Seoul. 공식 API 키·계정 권한을 확보했다는 의미와 공개 웹 탐색을 구분한다. 앱은 직접 HTTPS 요청 또는 사용자가 보는 WebView를 사용하며, PC stdio MCP를 앱 API로 호출하지 않는다.

## 미디어

- YouTube: 공개 모바일 검색 WebView에서 영상·채널 제목과 출처·게시 상대시각을 읽는다. 검색 결과는 앱의 GoalStore에 저장한다. 영상 전체 내용 분석·다운로드·재업로드 없음. 플레이어 대신 원문 링크를 사용한다. 공식 search.list API는 키 미설정으로 auth_required이며 현재 실행 경로는 공개 웹이다. 공식 근거 https://developers.google.com/youtube/data/reference/rest/v3/search/list .
- Google News: 공개 RSS 검색을 앱에서 직접 호출. 1MiB/15건 제한, 타임아웃, 요청 중복 억제, 10분 캐시. 제목·발행처·발행시각·원문 링크만 표시. 최신성은 when:7d, 언어는 hl/gl/ceid에 반영한다. 본문 전문 재배포 없음. 분류는 검색 목적이며 콘텐츠 내용을 분석한 판정이 아니다.
- 네이버 웹: 공개 검색 페이지의 블로그 원문 링크를 읽는 선택 경로. 로그인·접근 제한 시 실패 상태를 표시한다.
- Threads: auth_required. 토큰·권한·심사를 확보하지 않았고 라이브 검색을 완료하지 않았다. https://developers.facebook.com/docs/threads/keyword-search .
- Instagram/Reels: permission_required. 일반 사용자 개인화 피드 조회 미지원. 임의 인증정보를 추출하지 않는다.

## 상품·전문가

- 11번가: 실제 검색 결과의 상품 제목·상품 ID·HTTPS 상세 주소·검색 표시가·명시된 배송비를 읽는다. /products/m/ 주소의 HTTP 리다이렉트를 피하기 위해 동일 상품의 HTTPS /products/ma/ 경로로 연결한다. 검색 표시 판매가와 조건부 할인·쿠폰을 동일시하지 않는다. 0.2.1부터 prdNo 형식도 안정적인 상품 ID로 복원하며 옵션 파라미터를 보존한다. 상품 ID가 없는 후보는 제외한다. 옵션·실판매자·재고·최종 총액이 미확인인 후보는 미검증 상태다.
- 네이버쇼핑: 새 앱 세션에서 로그인 요구 확인(auth_required). 기존 PC MCP에서 동작했다는 사실로 새 앱 세션의 성공을 주장하지 않는다. 카탈로그 집계 주소를 특정 판매처 오퍼로 저장하지 않는다. 종료된 네이버 쇼핑 검색 API를 호출하지 않는다.
- 쿠팡: 공개 검색 연결과 고정 DOM 추출기 구현. 실제 환경의 접근 제한 여부는 실행 보고서에 기록한다. 0.2.1의 고정 DOM 검사에서는 itemId/vendorItemId와 미확인 옵션 파라미터를 보존하고 알려진 추적 파라미터만 제거한다. 옵션별 URL을 별도 후보로 유지한다. 이 검사를 라이브 상품·옵션 확인으로 간주하지 않는다. 판매자 상품 관리 API·소비자 주문 API를 혼동하지 않는다.
- 토스쇼핑: unsupported. 공식 소비자 상품 조회·주문 경로 미확보.
- 인프런/K-MOOC: 공개 강의 탐색 연결. 전문가 가격·서비스 범위·시간·구매 조건 비교는 미지원.
- 가격 비교: Product/Offer와 Need를 구분할 저장소 및 금액·동일 옵션 검증 규칙이 있다. 현재 라이브 후보의 동일 제품·옵션·신품 상태·최종 총액이 확정되지 않았으므로 통합 최저가 비교 완료로 표시하지 않는다. 단일 플랫폼의 여러 후보를 여러 플랫폼에 직접 조회한 결과처럼 세지 않는다.
- 주문: 기기 내 구매 초안과 멱등 키 저장, 사용자 확인 후 정확한 원본 상품 화면으로 handoff. 링크 클릭·앱 복귀를 구매 성공으로 기록하지 않는다. 실제 구매/결제·주문 제출은 실행하지 않는다. 사용자 직접 구매 표시는 self_reported.
- 알림: 기본 OFF. 사용자가 가격 조건을 저장·삭제할 수 있으나 manual_only이며 활성화되지 않는다. 앱 종료 후 자동 감시·푸시는 미지원.

## 사람·장소·실행

- 문토: 공개 추천 모임 목록의 실제 링크를 표시. 서버 검색 경로는 미확보다. 공개 목록 안에서 목표별 단어(운동/대화/스터디/부동산 등)를 포함하는 카드만 기기 내에서 읽는다. 지역·모집 상태를 검증하거나 전체 모임을 검색한 것으로 표시하지 않는다. https://www.munto.kr/ko .
- Meetup: 키워드 검색 연결과 이벤트/모임 링크 추출. 참가·DM·실제 매칭 확정은 실행하지 않는다.
- 누비 커뮤니티: 서버·다중 사용자 인증 없음. 정직한 빈 상태 및 본인 프로필의 로컬 초안·철회만 지원한다. 공개 동의를 체크해도 외부로 게시되지 않는다. 신고/차단/두 계정 간 서버 권한 검증은 미구현이다.
- 카카오맵: 목적에 맞춘 장소 검색과 공개 결과 링크 추출. 현재 위치·실시간 영업·예약을 추정하지 않는다.
- 집 사기: 울산 아파트에 관한 네이버 공개 웹 검색과 청약홈 공식 사이트 연결. 네이버 부동산 직접 지도 경로는 검색어/좌표가 소실되어 서울 기본 지도로 이동하는 것을 실기기에서 확인해 제거했다. 매물 구조화 조회·가격 비교는 미지원이다. 검색 결과의 내용·지역·매물 유효성, 청약 자격·대출 조건은 원문 확인이 필요하며 자동 신청하지 않는다.
- 목표 캘린더: 기기 SQLite의 목표별 일정 CRUD·완료·출처·Asia/Seoul 날짜 저장. 시스템 캘린더 저장 성공을 대신 주장하지 않는다. UNIST 학사일정 및 기존 할 일·브라우저 도구를 보존한다.

## 실행 경계

검색어는 규칙 기반으로 생성하며 AI 추론이라고 표시하지 않는다. 단일 WebView 작업의 세대 번호·URL·공급자·검색어를 다시 확인한 후 정규화한다. 외부 페이지가 네이티브 함수를 호출할 JavaScript 브리지는 없다. HTTPS와 허용 도메인만 시작·탐색하며, 인증은 사용자에게 넘긴다. 상태는 실제 응답/결과를 기반으로 표시하고 가상 결과를 넣지 않는다.
