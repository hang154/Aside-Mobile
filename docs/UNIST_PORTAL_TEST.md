# UNIST 포털 WebView 연결 검사

## 실기기 결과 — 2026-10-31

- 대상: `ai.decisionos.nubi.unistlive` 0.1.3, 사용자 Android 태블릿의 누비 WebView.
- UNIST 안내에 나온 `https://portal.unist.ac.kr`을 열자 Microsoft 계정 로그인 화면으로 연결됐다. 페이지의 `로그인 옵션`을 직접 눌렀다가 돌아갔고, 누비의 `화면 관찰 → 항목 선택 → 실행`으로도 `로그인 옵션` 화면을 열었다.
- 기본 로그인 화면에서 누비 관찰 결과는 네 항목이었다. 해당 목록에는 `다음` 입력 제출 버튼이 나타나지 않아 모든 로그인 화면 요소가 관찰·제어된 것은 아니다.
- 계정 정보·비밀번호·인증번호를 입력하거나 로그인한 것은 아니다. 로그인 후 학사·식단·메일 접근, 세션 유지 및 작동은 미검증이다.
- 녹화는 로그인 전 화면에서만 진행하고 종료했다. 영상은 로컬에만 저장한다. 로그인 절차 중 캡처를 계속하지 않으며 인증 정보는 사용자에게 직접 입력받는다.

학교의 [포털 안내](https://notice.unist.ac.kr/webpage/portal/index.html)는 해외에서 포털에 접속하려면 VPN이 필요하다고 안내한다. 이 시험은 태블릿 네트워크에서 로그인 화면이 열리는 것만 확인했다. 로그인 후 웹 페이지와 학식 정보의 자동화 가능성을 보장하지 않는다.
