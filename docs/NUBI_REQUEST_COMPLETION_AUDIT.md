# 누비 요청 대조 및 검증 현황

기준: 2026-11-01. 대화에서 요청한 기능과 저장소·태블릿 시험 기록을 대조했다. ‘조회 검증’은 실제 예약·신청이나 앱 전체 완성을 뜻하지 않는다. 이전 문서의 과거 시점 기술보다 이 문서와 최신 실험 기록을 우선한다.

| 요청 | 근거가 있는 현재 상태 | 남은 작업 |
|---|---|---|
| 사용자 입력 → Qwen → UNIST 포털 | 누비 채팅에서 장학 제목 검색, 검색 결과 선택 및 본문 요약, 예비수강신청 기간 확인을 실기기에서 시험 | 임의 요청 전반의 정확성·오류 복구·세션 만료 복구 |
| 학사·장학·전체 게시판 | 세 게시판 목록과 선택 본문, 학교 서버의 제목 검색과 검색 결과의 첫 페이지와 2페이지에서 공지 선택을 실계정으로 확인 | 이미지 본문 해석, 3페이지 이후 선택과 전 게시물의 본문·첨부 수집, 다양한 검색어 시험 |
| 지속 수집·휴대기기 알림 | PC 사용자 서비스가 세 게시판 첫 페이지를 15분 주기로 감시. 모의 변경의 기기 알림 시험 | 기기 단독 주기 실행, PC·USB 없이 알림, 본문·첨부 변경·마감 추적, 세션 재인증 |
| 학생별 관련성 | 두산 2027 공고의 명시 조건을 제공된 사실로만 분류 | 다른 공고의 조건 추출·검증, 사용자 프로필 연결, 불명확한 조건 표시 및 정확도 평가 |
| 수강신청 | 예비수강신청 화면과 표시 기간, 과목 검색 결과 확인 | 정원 변경 감시→해당 과목 연결, 접수 기간 중 실제 선택·신청 결과 검증. 현재 접수 기간이 아님 |
| 학교 메일→문서→임시저장 | 실제 COOP 메일 본문→테스트 DOCX→수신인 없는 첨부 초안→재확인, 앱 채팅 Qwen 경로 시험 | 모든 메일 분류·주기 감시, 학교 원본 HWP 양식 다운로드·작성, 수신인 정확성, 다른 양식과 세션 복구 |
| 외부 채용·논문·지도·숙소·쇼핑 | 사람인·원티드, OpenAlex, 네이버·카카오 지도, Booking, 네이버 가격비교를 각각 로컬 MCP/태블릿에서 제한적으로 조회한 기록 | 누비 채팅 Qwen의 전체 작업 연결과 반복 검증, 원문·가격·영업조건·선택 후 처리. 결과와 정책은 변할 수 있음 |
| 코레일 | 승차권 조회 화면 접근 기록 | 열차 결과 조회·선택·예약. 이전 자동화 시험에서 접근 제한 `-8002` |
| 학식·동아리·친구 조율·과외·날씨·이벤트 | 일부 공식 식당 위치/운영시간, 동아리 소개와 날씨 조회 기록 | 당일 식단, 동아리 모집·운영, 양측 누비 일정 조율, 일정·급여 관리, 행사별 검증 및 사용자 여정 |
| 인스타·다른 앱·BlackBox/Qwen 제어 | 별도 시험 이력 존재 | 10개 앱의 완전한 조작과 누비/Qwen/MCP 통합을 검증했다고 볼 근거 부족 |
| 포털 팝업·로그인 유지 | 기존 웹 세션에서 직접 게시판으로 이동하는 우회 경로 확인 | 로그인된 기존 설치 앱에 팝업 수정본을 적용한 실제 검증 |
| 홍보 영상·에타 배포 | 이전 앱 화면과 소개 초안·영상 기록 존재 | 현재 기능 기준 재촬영·편집, 개인정보 제거와 실제 기능 대조, 배포용 계정 연결·안내·실기기 회귀 |

학교 세션은 `ai.decisionos.nubi.unistlive`, 누비 채팅은 별도 패키지이며 현재 PC 중계와 USB 디버깅에 의존한다. 서비스 연결이 곧 기능 완성을 의미하지 않는다. 전화 시험은 사용자가 제외했다. 실제 주문·신청·발송 여부는 서비스의 확인 결과로만 표시한다.
