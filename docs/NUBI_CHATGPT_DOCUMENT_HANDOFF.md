# 누비 문서와 ChatGPT 연결

2026-11-01: 생성된 문서 카드와 보관함에 `ChatGPT에 DOCX 첨부` 동작을 추가했다. 생성 결과에 HWPX와 DOCX가 함께 있으면 HWPX 항목에서도 같은 결과의 DOCX를 준비한다. 파일은 누비 브라우저에서 ChatGPT를 열고 사용자가 첨부를 누른 후 준비된 파일을 선택할 때 전달한다. 원본 문서가 자동으로 수정되거나 대화가 자동 전송되지는 않는다.

Android WebView 파일 선택을 연결했고, 준비된 파일의 접근은 `chatgpt.com` HTTPS 화면과 사용자 확인에 한정한다. 별도 파일 선택기도 지원한다. 임의의 HWP/HWPX 파일을 DOCX로 변환하는 기능은 이 연결에 추가하지 않았다. OpenAI 공식 문서에 DOCX는 지원 형식으로 나와 있지만 HWP/HWPX는 명시되어 있지 않다.

태블릿에 빌드·설치했다. 합성 파일로 준비된 파일 확인 대화상자와 콘텐츠 URI 읽기를 확인하는 계측 시험이 한 차례 통과했다. 마지막 재시험에서는 확인 대화상자를 찾지 못했으며 당시 다른 앱이 기기 전면에 있었다. 그 원인을 확정하지 않았고, 사용자 계정으로 ChatGPT에 로그인한 뒤 실제 업로드, 편집 응답 및 수정된 파일 저장은 아직 검증하지 않았다. 개인 문서는 시험에 사용하지 않았다.
