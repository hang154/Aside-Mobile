# 누비: 캠퍼스 홍보 초안

아래는 게시 전 검토용 초안이다. 운영자가 누비를 만든 사람이라는 사실과 테스트 단계, 실제 설치 링크·문의처를 명시한다. UNIST 에브리타임의 홍보·모집 규칙을 확인하고, 같은 내용을 여러 게시판에 반복 게시하지 않는다. 현재 되는 기능은 웹 검색·할 일 저장 수준이며 자동 예약·발송·메일 연동은 준비되지 않았다.

1. **학교 공지** — “학사 공지 찾으러 학교 홈페이지 메뉴 몇 번씩 들어가게 되더라고요. 학교 이름을 넣으면 관련 공지 검색으로 바로 이어지고, 다시 볼 일은 저장하는 앱을 만들어 보고 있어요. 아직 시험판인데 같이 써보고 불편한 점 알려주실 분 있을까요?”
2. **학식** — “오늘 학식 뭐 나오는지 볼 때 메뉴까지 찾아가는 게 은근 귀찮아서 만들고 있어요. 누비에서 학교 식단 검색으로 바로 갈 수 있습니다. 식단 자동 연동은 아직 준비 중이에요.”
3. **KTX** — “집 내려갈 때 열차 시간표 찾는 것부터 귀찮은 분 있나요? 누비에서 관련 검색을 열고 여행 준비를 할 일로 남길 수 있어요. 표 예매는 코레일에서 직접 해야 합니다.”
4. **논문** — “연구 주제 자료 찾는 분들께: 관심 주제를 적어 검색하고 나중에 볼 일을 저장하는 흐름을 시험하고 있어요. 자동 논문 추천은 아직 아니고, 원하는 기능을 듣고 싶습니다.”
5. **과외·알바** — “과외나 알바 구할 때 공고가 여기저기 흩어져 있죠. 관련 검색과 할 일 관리를 한곳에서 시작하는 작은 앱을 만들고 있습니다.”
6. **선물·초콜릿** — “11월 11일 전에 초콜릿 고를 때 뭐부터 봐야 할지 모르겠어서 관련 상품을 쉽게 찾는 바로가기를 넣어봤어요. 가격은 쇼핑몰에서 직접 확인해야 합니다.”
7. **기말 이후·연말** — “기말 끝나고 뭐 할지 미리 생각하는 분? 주말 코스나 연말 행사를 찾아보고 후보를 할 일에 적어둘 수 있게 해봤어요. 지금은 울산 검색 예시가 들어가 있습니다.”
8. **동아리** — “동아리 행사 준비할 때 할 일이 계속 흩어지더라고요. 지금은 개인 할 일로 저장하는 시험판이고, 같이 일정 맞추는 기능은 준비 전입니다. 동아리 운영할 때 가장 귀찮은 걸 알려주세요.”

## 촬영 구성

실기기 화면으로 ① 누비 홈과 학교 입력 ② 학사 공지 검색 ③ 결과 원문 확인 ④ 동아리 할 일 초안·저장 ⑤ 앱 재실행 후 다시 찾기를 짧게 보여준다. 미구현 예약이나 친구 대화는 영상에 성공한 것처럼 넣지 않는다. 아직 위 전 과정을 최종 빌드에서 검증하지 않았으며, 촬영·검증 후 실제 화면으로 교체한다.
