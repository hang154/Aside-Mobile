# UNIST 포털과 학교 메일 검증

- 2026-10-31 USB 연결 태블릿의 기존 누비 WebView에서 Outlook 로그인 이후 `https://portal.unist.ac.kr/`에 접속했다. Microsoft 로그인 세션을 통해 포털 홈이 표시되었고 학사 메뉴와 하위 메뉴를 열었다.
- 별도의 연결된 Outlook 도구로 학교 계정 프로필과 최근 메일 5건을 조회하여 본문을 읽었다. 이는 누비 APK 내부 Microsoft Graph 연동의 성공을 뜻하지 않는다.
- 홈 화면에 UNIST 포털과 Outlook 웹을 여는 버튼을 추가했다. 앱별 WebView 세션은 격리되므로 기존 앱과 별도 설치하는 시험 앱에서는 다시 로그인해야 할 수 있다.
- 누비 자체 Graph 연동에는 해당 앱의 Microsoft Entra 앱 등록과 Android 패키지·서명에 맞는 리디렉션 구성, 위임 권한 및 사용자 로그인/필요시 학교 관리자 승인이 필요하다. 기존 웹 세션이나 외부 도구의 자격 증명을 재사용하지 않는다. 메일 본문에는 `Mail.Read`가 필요하다.
- 실계정 로그인 및 메일 화면은 녹화하지 않았고 본문·계정·토큰을 이 저장소에 저장하지 않았다.
