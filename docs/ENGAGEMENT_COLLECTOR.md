# 화면 이벤트 수집기 0.9.1

Aside 앱 설정에서 수집 대상 앱을 직접 선택하고 별도 접근성 수집 서비스를 활성화한 후 수집 시작을 누른다. 별도의 앱 내 동의 확인 창은 사용하지 않는다. 시작 전 Android 알림 권한이 필요하다. 서비스가 연결되고 수집이 켜져 있으면 상태 알림을 표시하고, 알림을 누르면 설정 화면으로 돌아간다. 수집 중지와 기록 삭제는 앱에서 할 수 있다. 기본값은 꺼짐이며 앱 선택도 없다.

선택한 외부 앱의 창 전환, 클릭, 스크롤의 **이벤트 종류**, 앱 패키지, 시각과 창 표시 구간을 로컬 SQLite에 기록한다. Aside WebView에서는 페이지 열기·화면 터치와 표시 구간을 기록한다. 화면 내용, 입력값, URL, 클릭 위치와 요소의 이름은 수집하지 않으며 접근성 수집 서비스는 노드 내용을 읽지 않는다. 앱을 사용하는 시점과 종류 자체도 민감할 수 있다. 화면 잠금이나 화면이 꺼진 상태에서는 기록하지 않는다. 사용자에게 보이는 선택 화면에는 Chrome, 카카오톡, Android 설정과 Aside가 있으며 추가 앱은 패키지명으로 직접 넣는다.

데이터는 앱 내부에만 저장되며 최근 24시간·5,000건 기준으로 다음 기록 또는 기록 조회 시 정리된다. 앱을 사용하지 않는 동안 시한 도달 즉시 삭제되는 구조는 아니다. 앱 백업은 끄고 외부 전송은 구현하지 않았다. OS가 서비스를 중지하거나 이벤트가 누락될 수 있어 상시 실행이나 연속 기록을 보장하지 않는다. 표시 구간은 사용자가 보거나 관심을 가졌다는 증거가 아니며, 창이 중단·잠금되면 구간이 빠질 수 있다. 감정·반응·의도 추정, 광고 콘텐츠 분석, 정확한 요소 선택과 텍스트 수집은 구현하지 않았다.

Android 서비스 상태, 알림 허용, 선택 앱과 잠금 상태가 충족되지 않으면 기록하지 않는다. 이 서비스는 화면 내용을 수집하거나 접근성 제스처를 수행하지 않는다. 별도의 기존 화면 조작 서비스는 유지한다. Google Play 배포는 접근성 API의 용도 제한과 고지·동의·선언을 별도로 검토해야 한다.
