# 피클 기능 대비 Aside 실현 가능성 점검

확인일 2026-10-30. 범위는 [피클 공식 소개](https://pickle.com/ko)와 [피클 한국 App Store 공식 설명](https://apps.apple.com/kr/app/%ED%94%BC%ED%81%B4-%EB%82%98%EB%A7%8C%EC%9D%98-ai-%EC%97%90%EC%9D%B4%ED%8A%B8/id6795790129)에 명시된 사용자 기능이다. 소개는 제공자의 설명이며 이 문서는 피클의 내부 구조나 계정별 실제 가용성을 검증한 것이 아니다. 아래의 가능은 원리상 가능하다는 뜻이지, Aside에서 구현·실행 성공을 뜻하지 않는다.

## 이번 변경

로컬 모델의 검색·네이버 실행 제안을 승인하면 시스템 외부 브라우저가 아니라 Aside WebView에서 열도록 연결했다. SPA 내부 탐색 시 주소 표시와 관찰 결과를 갱신하도록 했다. 이는 단일 기기에서의 기초 동작이며 외부 서비스의 실제 예약·결제·전화 대행을 구현한 것이 아니다. 각 기능은 사용자 지정 목표와 실제 계정 연결·대상 환경이 갖춰진 후 별도의 끝까지 실행 검증이 필요하다.
