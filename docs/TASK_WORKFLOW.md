# Aside 할 일 MVP

사용자가 검색·전화 준비·예약 준비·쇼핑 준비·모임 준비 중 유형을 선택하고 할 일을 등록한다. 목록에서 관련 정보를 전용 WebView로 검색하고, 사용자가 직접 진행 중 또는 완료로 표시하거나 삭제할 수 있다. 등록된 제목·유형·상태·최종 변경 시각은 앱 내부 SQLite에 저장되며 재실행 후 유지된다. 완료 표시는 사용자의 수동 기록이며 실제 통화·주문·결제·예약 성공을 의미하지 않는다.

전화 대행, 서비스별 자동 탐색·실제 주문·결제·예약, 알림·선제 제안, 상대방과의 조율, 외부 에이전트 연결과 감사 로그는 이 화면에서 구현하지 않았다. 비밀번호·인증번호·카드정보를 할 일에 입력하지 않는다. 기존 사용자 앱을 보존하기 위해 이번 실험 APK는 별도 패키지로 설치한다.

AI 제안 화면에서는 요청이 바뀌면 이전 제안을 무효화하고 실행 버튼을 비활성화한다. 추론이 진행 중일 때도 오래된 응답은 새 요청에 적용하지 않는다.

## 실기기 확인 — 2026-10-30

태블릿 `ai.decisionos.aside.tasks2` 0.8.1에서 `Busan Airbnb` 할 일 생성 → 진행 중 표시 → 강제 종료 후 복원 → 전용 브라우저 검색을 확인했다. 에어비앤비 부산 숙소 목록과 숙소 상세가 열렸으며, 실제 여행의 체크인·체크아웃과 인원은 지정되지 않아 예약 가능 여부 및 최종 비용은 확정하지 않았다. 완료 표시를 취소했을 때 진행 상태가 유지되는 것을 확인했다. 별도의 테스트 할 일로 완료 표시와 삭제를 확인하고 테스트 항목을 제거했다.
