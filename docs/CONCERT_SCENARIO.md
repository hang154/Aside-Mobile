# 시나리오 01 — 공연 후 귀가와 숙박

대구에 사는 두 사람이 서울 공연의 앵콜까지 보고 귀가한다. 공연 종료, 퇴장과 역까지의 이동 시간을 합쳐 역 도착을 계산하고, 직접 확인한 귀가 열차 출발과 비교한다. 막차가 어렵다면 숙박 후 다음날 귀가하는 비용을 비교한다.

1. 홈에서 `공연 원정 비교하기`를 선택한다.
2. 출발지·공연 도시·장소를 입력하고 검색 버튼으로 열차와 숙소 정보를 확인한다.
3. 확인한 공연 종료 시각, 퇴장·이동 시간, 귀가 열차 출발 시각, 인원, 예산, 열차 요금과 숙소 금액을 입력한다.
4. `비교하고 저장`을 누르면 역 도착 시각과 열차까지의 여유, 당일 및 숙박 후 귀가의 총액·예산 초과 여부를 확인한다. 저장된 값은 기기에 남아 재실행 후 복원된다.
5. 사용자가 각 서비스에서 최신 운행, 빈자리, 가격과 예약 조건을 확인하고 직접 예매한다.

연습용 시나리오 값은 가상이다. 2026-11-14 22:30 종료, 퇴장 30분, 이동 40분이면 23:40 역 도착이다. 23:20 열차는 20분 일찍 출발하므로 어렵다. 두 명의 당일 요금 각 30,000원은 60,000원이고, 숙소 100,000원과 다음날 요금 각 30,000원은 160,000원이다. 공연비·출발 교통비·식비는 계산에 포함되지 않는다.

현재 값은 사용자가 검색 결과를 확인해 입력한다. 실시간 시간표·가격 수집, 자동 최적화와 예약·결제는 구현하지 않았다. 한 번에 한 계획만 저장한다.
