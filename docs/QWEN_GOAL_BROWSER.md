# Qwen과 누비의 네 목표 탐색

0.2.3부터 앱의 목표별 채팅 전송 버튼이 호스트 작업기를 자동 실행한다. 최신 화면과 실행 계약은 [AGENT_CHAT.md](AGENT_CHAT.md)를 따른다. 아래 실행 명령과 초기 검증 기록은 명령행 경로 설명이다.

운동(fitness), 연애(love), 학점(grades), 집 사기(home)는 같은 목표 저장소와 네이티브 작업실을 사용한다. 작업실의 **Qwen에게 이 목표 탐색 맡기기**를 눌러 전용 브라우저를 열고 **Qwen 원격 연결**로 페어링한다.

Qwen은 연결된 모델 서버에서 실행된다. 태블릿 내 로컬 모델 추론이 아니다. 목표 주제와 공개 검색 결과 메타데이터가 모델 서버로 전달된다. 로그인 정보, 메일 본문, 계정 화면을 읽는 기능은 제공하지 않는다.

흐름: Qwen → stdio MCP → 로컬 HTTPS 제어 요청 → 인증·인증서 고정 HTTPS 중계 → 실제 태블릿의 전경 WebView → 고정 DOM 추출기 → Qwen → 목표별 요약 저장.

## 도구

- `nubi_goal_explore`: Qwen이 정한 목표와 최대 세 공급자·검색어를 받아, 위 도구를 실제 태블릿에서 순차 실행한다. 각 공급자 결과를 함께 반환하며 마지막 페이지의 observation_id만 선택할 수 있다.

- `nubi_goal_open`: 네 목표 중 하나를 열고 실제 목표 ID와 주제 반환.
- `nubi_goal_search`: 허용한 공급자에서 검색 시작. 결과 수신은 별도 observe가 필요하다.
- `nubi_goal_observe`: 최대 8개 실제 결과 메타데이터 또는 선택한 원문의 제목과 주소 반환.
- `nubi_goal_select`: 현재 목표의 최신 observation_id와 인덱스로 원문 탐색. 오래된 목록은 거부.
- `nubi_goal_report`: 관측한 출처만 포함하는 한국어 요약을 해당 목표에 저장.

공급자는 YouTube, 네이버 웹, 11번가, 문토, 카카오맵, 부동산 관련 네이버 검색, K-MOOC, 인프런이다. 실제 지원 범위는 기존 고정 추출기의 범위를 따른다. K-MOOC는 홈페이지 탐색이며 강좌 검색 API가 아니다. 문토는 공개 목록의 단어 필터이며 실시간 매칭·참가 확정이 아니다. 동영상·상품 본문 분석, 구매·결제·신청·메시지 전송과 백그라운드 탐색은 제공하지 않는다.

## 실행

기존 `nubi-relay*`, `qwen-tablet-agent.py`와 독립된 포트 18444를 사용한다. 인증키는 권한 600인 로컬 파일에 보관하고 Git·캡처·로그에 넣지 않는다. 중계 서버는 `nubi-goal-relay.py --cert ... --key ... --token-file ...`로 실행한다. 태블릿의 주소는 태블릿에서 접근 가능한 호스트의 네트워크 주소여야 한다. 컨트롤러 명령은 localhost만 받는다.

호스트에서 환경변수 `NUBI_GOAL_RELAY_TOKEN_FILE`, `NUBI_GOAL_RELAY_CA_FILE`을 설정한다. 필요시 `NUBI_GOAL_RELAY_URL`을 설정한다(기본 `https://127.0.0.1:18444`).

`python3 opencli-nubi/qwen-goal-agent.py --goal fitness --trace-file /absolute/local/fitness.json`

나머지는 `--goal love`, `grades`, `home`으로 순차 실행한다. 실제 브라우저는 하나이므로 병렬 실행하지 않는다. 검색 결과는 제목·주소·종류·작성자·표시 가격·게시 시각만 모델에 전달한다. 같은 오류/준비 중 응답이 두 번 이어지면 observe/select를 일시적으로 도구 목록에서 제외해 다른 검색이나 부분 보고로 넘어가도록 한다. 모델 응답 시간 초과는 한 번만 재시도한다. 목표를 열어 실제 주제·개인화 설정을 먼저 확인하는 bootstrap은 호스트가 수행하며, 검색어·후보 선택·요약은 Qwen이 결정한다. 요약 저장 응답이 성공하면 추가 모델 호출 없이 그 요약을 최종 결과로 반환한다.

모델은 기존 Azrael bearer-file 연결을 사용해 `Qwen3.8-27B-abliterated-AWQ-W4A16`을 요청하고 응답 모델 ID가 다른 경우 중지한다. 로그인 비밀을 채팅에 입력할 필요가 없다.

앱 화면을 벗어나거나 연결 끊기를 누르면 폴링과 늦게 도착한 결과 전달을 중단한다. 앱 재실행 후에는 명시적으로 다시 연결한다. 중계 프로세스 종료와 임시 인증키 폐기는 실행자가 담당한다. 캡처·영상·전체 모델 추적은 로컬에만 보관한다.

## 사용자 지시로 탐색하기

아즈라엘에서 실행한 호스트 Python 실행기가 기존 Azrael Qwen 연결을 사용한다. Qwen 응답의 tool_calls를 실행기가 MCP로 전달한다. 아즈라엘의 주 대화 모델을 Qwen으로 교체하거나, 앱의 새 요청을 아즈라엘 작업으로 자동 접수하는 기능은 아니다.

```bash
python3 opencli-nubi/qwen-goal-agent.py --goal fitness \
  --task '맨몸 초보자 운동 영상 하나를 찾아 제목을 확인해줘. 쇼핑과 모임은 제외해.' \
  --trace-file /absolute/local/user-task.json
```

`--task`에서는 사용자 문장을 그대로 전달하고, 복합 탐색 도구를 제외하며 첫 도구 강제를 해제한다. Qwen이 허용된 공급자, 검색어, 순서, 실제 후보와 요약을 선택한다. 목표 열기 bootstrap만 호스트가 수행한다. 사용 가능한 공급자·읽기 전용 동작·최대 단계 수 안에서의 자율 탐색이다. `--task`가 없으면 기존 세 범주 탐색 순서를 지정하는 검증 레시피를 유지한다.

trace에는 사용자 지시, 실행 모드, 시작·종료 시각, 실행기/MCP 파일 SHA-256, 응답 모델 ID, 모델의 tool_calls와 실제 도구 결과를 기록한다. 이 파일은 로컬에만 보관한다. HTTP 429/502/503/504 또는 타임아웃은 한 번만 재시도하고 실패를 기록한다.

2026-10-31 최초 사용자 지시 실기기 재검증은 모델 게이트웨이 HTTP 502로 중단됐다. 복구 후 같은 fitness 목표에서 영상 전용·쇼핑 전용 지시를 순차 실행해 Qwen의 서로 다른 공급자 선택, 실제 결과 읽기와 요약 저장을 확인했다. 쇼핑 가격 조건은 통과했고 영상은 원문 로딩 실패와 근거 없는 구성 설명이 있어 부분 통과다. 세부 결과는 `reports/QWEN_USER_DIRECTED_VERIFICATION.md`를 따른다. 기존 네 목표 성공 기록은 고정 범주 레시피 검증이다. `python3 opencli-nubi/test-user-directed-agent.py`는 모의 모델·MCP로 지시 전달, 강제 도구 제거, 모델 선택 인자 전달과 다른 모델 거부를 확인한다. 실기기 검증을 대신하지 않는다.
