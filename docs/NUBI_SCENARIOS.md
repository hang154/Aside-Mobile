기준일 2026-10-30. 첫 배포 대상은 UNIST다. 특정 학교의 공지·학식·시험 일정을 실제로 연동했다고 가정하지 않는다. 누비의 첫 목표는 **학생이 학교생활 중 반복해 확인하는 정보를 쉽게 찾고, 이어서 할 일을 남기는 것**이다. 피클과 범용 기능을 모두 겨루기보다는 학교별 출처·학생 상황·친구 모임 흐름의 완성도를 검증한다. 근거로 삼는 피클의 대외 기능 소개: https://pickle.com/ko

## 실험 우선순위: 2026-10-30 ~ 11-02

- **첫날:** UNIST 공식 학사일정과 학생 정보의 접근 조건을 확인하고, 학식 정보의 접근·갱신 방식을 검증한다. 사용자 5~10명의 실제 불편과 이용 환경을 듣고, 기기별 설치 경로를 확인한다.
- **둘째 날:** 학사 공지·학식의 학교별 실제 수집과 출처·날짜 표시를 구현한다. 실패·변경을 감지하고, 학생이 할 일에 저장해 다시 찾는 흐름을 검증한다.
- **셋째 날:** 소수의 동의한 학생에게 설치·첫 사용·다음 날 재방문을 검증하고 문제를 고친다. 설치 안내, 개인정보 처리와 수집 기능의 실제 상태, 지원 연락처와 피드백 경로를 준비한다. 3일 내 일반 공개는 공식 정보 연결·기기별 배포·실사용자 검증 결과에 따라 결정한다.

측정은 학교별 공지·식단 확인 성공, 첫 사용자가 스스로 끝낸 비율, 다음 날 다시 돌아온 비율, 저장한 할 일 수, 정보 오류·불필요한 알림의 사용자 신고를 우선한다. 사용자 행동만으로 개인 의도·감정을 단정하지 않는다.

## 실제 데모와 피드백에 필요한 준비

실제 단말 캡처는 조작 결과와 동일한 앱 버전·화면을 사용한다. 학교 공지와 식단 등은 출처·조회 시각을 표시하고 로그인 정보와 개인 내용은 촬영에서 제외한다. 홍보 문구는 실제 작동한 기능만 적고, 예매·메일 발송·누비 간 자동 대화는 기능 완성 및 실기기 검증 전에는 제공한다고 쓰지 않는다. 배포 링크·문의처·모집 인원과 게시판 규칙은 학교 확인 후 정한다.

## UNIST 공식 정보와 차별화 가설

- [UNIST 공식 학사일정](https://www.unist.ac.kr/unist/education/academic/schedule.do)은 공개 웹페이지다. 누비는 공식 페이지가 사용하는 데이터 경로에서 향후 60일을 수동 조회하고 원문을 여는 버튼을 제공한다. 주기적 자동 수집·개인별 적용 판단·알림은 아직 없다.
- [UNIST m-Portal](https://play.google.com/store/apps/details?id=kr.ac.unist.mportal) 공식 앱은 학사일정, 시간표, 주간 메뉴 등을 제공하고 사용 시 포털 로그인이 필요하다고 안내한다. 따라서 “UNIST에는 학사 일정이나 학식 앱이 없다”는 주장은 사용하지 않는다. 누비의 후보 차별점은 여러 출처의 학생별 정보와 반복 작업을 한곳에 모으는 경험이며, 학생 조사로 검증해야 한다.
- 학사 공지, 학식, 취업 게시판의 개인 계정 접근 및 동기화는 별도 연동·검증 전까지 제공한다고 표시하지 않는다. 개인정보·계정 연결과 사용자별 알림은 별도 구현이 필요하다.

## 0.1.2 최종 빌드·실기기 검증

- 2026-10-30, Lenovo 태블릿에 별도 패키지 `ai.decisionos.nubi.pilot`을 설치했다. 기본 학교 UNIST와 누비 홈을 확인했다.
- 17개 카드 각각에 대해 `할 일에 담기`가 올바른 제목(학교가 필요한 경우 `UNIST` 포함)을 넣는지 실기기에서 확인했다. 17개 카드의 `웹에서 확인`이 예상한 검색어를 WebView에 전달하는지도 실기기에서 확인했다. 이는 검색어 전달 검사이지 결과의 정확성이나 실제 예약·신청 성공 검증이 아니다.
- UNIST 공식 학사일정 페이지가 WebView에 표시됐고, 학사 공지를 할 일로 저장해 앱을 강제 종료 후 다시 열었을 때 복원됐다. m-Portal 안내는 Google Play 앱으로 연결됐지만 기기에서 Play 로그인이 필요해 목록 화면을 확인하지 못했다.
- CI 41071637601에서 17개 시나리오 조건·명령 파서·제안·공연 계산·정적 검사가 통과했고 APK가 빌드됐다. SHA-256 `75bed17e8d912bdee50a5e6fcc0332c2dfad04627402a379585102029be6e21e`.
- 실기기 녹화와 실제 앱 화면 캡처, 세 캡처를 순서대로 보여 주는 12초 무음 화면 미리보기는 로컬에만 보관한다. 이는 학생 반응을 검증한 홍보 영상이나 배포 완료의 근거가 아니다.
- 배포를 위해서는 학생 설치 경로와 정식 서명·업데이트 방식, 학교 공지·식단의 실제 연결과 출처·최신성, 학생 검증과 개인정보 처리, 문의 경로가 남아 있다. 현재 APK는 디버그 실험판이다.


## 0.1.3 UNIST 공식 일정 조회·최종 검증

UNIST 공식 학사일정 페이지의 데이터 호출을 이용해 오늘부터 60일의 일정을 앱 안에 표시한다. 화면에 공식 출처와 한국 시간 조회 시각을 보여주며 실패하면 원문을 확인하도록 안내한다. 공식 웹페이지의 데이터 경로가 바뀌면 동작이 중단될 수 있다. 진행 중인 일정의 누락, 사이트 장애·데이터 변경, 개인별 해당 여부와 자동 알림은 검증·구현하지 않았다.

2026-10-30 실기기에서 일정 조회와 새로고침 후 2026-10-30~12-29 범위 10건을 확인했다. 예를 들어 12월 14~18일 기말고사와 12월 19일부터의 겨울방학이 표시됐다. 17개 시나리오 각각의 검색어 전달 및 할 일 초안 검사를 최종 버전에서 다시 통과했고, UNIST 학사 할 일 저장·앱 강제 종료 후 복원도 확인했다. 검색어 전달은 검색 결과나 예약의 성공을 뜻하지 않는다.

CI 41073183164 및 APK SHA-256 `43672a927cbe50fd50469dc9b7d83903b485cf8ae1e35355437b182f5a13a6ed`. 최종 별도 패키지는 `ai.decisionos.nubi.unistlive`다. 실기기 영상 3개와 홈·일정·할 일 캡처, 캡처 3장을 연결한 12초 무음 미리보기는 로컬에만 저장했다. 0.1.2 및 이전 실험 패키지는 사용자 데이터 보존을 위해 남아 있다.
