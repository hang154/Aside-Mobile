# 누비 캐릭터 대화 UI 0.3.0

## 목적
Pickle의 공개 스토어·공식 사이트에 나타난 캐릭터 중심 대화, 흰 배경, 둥근 입력창과 하단 독을 참고하여 네 목적별 누비의 실제 Qwen 탐색을 한 화면에서 사용한다. assistant-ui / OpenBot의 메시지·실행 기록·파일·도구 화면 구성을 기존 작업공간 선택지로 유지한다.

## 화면과 동작
- 실행: 최근 목표의 대화. 목표가 없으면 운동 목표 생성.
- 상단 캐릭터 이름 또는 목적: 운동·연애·학점·집 사기 선택. 목표별 대화와 파일은 기존 저장소의 소유권 규칙에 따라 분리.
- 대화: 메시지를 해당 목표와 함께 기존 Qwen 실행 서버로 전달. Qwen이 MCP 검색·이동·관찰을 선택하고 실제 기기 WebView를 탐색한다. 서버 접속과 모델은 기존 연결 설정을 사용.
- 탐색: 네 목적 선택과 실제 브라우저 확인.
- 작업: 현재/최근 실행 기록, 이 목표 대화에서 생성한 DOCX/HWPX, 목표 일정·저장한 콘텐츠, 실제 브라우저.
- 내 정보: 연결 상태, 목표별 대화, 화면 선택과 목표 관리.
- 입력창 +: 작업과 파일 열기. 검은 전송 버튼은 실행 중 중지 버튼으로 변경.
- 메뉴의 화면 선택: 누비 / 작업공간 / 기존 화면. 입력 초안을 보존하며 실행 중에는 전환을 제한.

## 구현 범위
Android Java 네이티브 UI다. assistant-ui React 패키지나 Pickle 코드를 포함하지 않는다. 캐릭터와 아이콘은 누비의 자체 Canvas 도형이다. Pickle 로고·캐릭터·APK를 앱에 포함하지 않는다. 기존 Qwen/MCP, 캠퍼스 도구, 목표별 콘텐츠 저장 기능은 유지한다.

## 참고 조사와 한계
2026-11-01 태블릿 Aurora Store에서 Google Play의 com.pickle.client 설치 및 실행 확인. 시작 화면에서 Google/휴대폰 로그인이 필요해 로그인 이후 내부 화면은 직접 조사하지 않았다. 공개 스토어 화면과 공식 사이트의 배치가 참고 근거다. 따라서 로그인 이후 모든 화면의 픽셀 단위 동일성을 검증했다는 의미가 아니다. 제삼자 APK와 캡처는 로컬에만 보관한다. 설치에 한시적으로 허용한 Aurora REQUEST_INSTALL_PACKAGES는 ignore로 복구했다.
