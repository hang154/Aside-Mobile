# 누비 개발·검증 백업 현황

기준: 2026-11-01 (한국시간). 이 브랜치는 Aside Mobile에서 발전한 누비 태블릿·캠퍼스 프로토타입의 소스와 문서 백업이다. 실계정 세션, 비밀번호, 토큰, 로컬 데이터베이스, 사용자 문서와 화면 캡처는 포함하지 않는다.

## 주요 내용

- Android 누비 채팅과 학교 브라우저, WebView 팝업 처리, 원격 브라우저 중계 및 작업 상태 표시.
- OpenCLI/MCP를 통한 학교 포털 게시판·제목 검색·공지 본문, 수강 화면, Outlook 웹 메일 검색과 읽기, 문서 초안 및 첨부 임시저장, 공지 감시 도구.
- Azrael에 설정된 Qwen을 이용한 누비 사용자 입력 → 도구 호출 → 결과 표시 경로. 앱에서 실제 학교 메일 검색→테스트 DOCX→수신인 없는 첨부 초안→장학게시판 복귀가 수행된 시험 기록이 있다. 메일은 발송하지 않았다.
- 지도·숙소·논문·채용·쇼핑 등 외부 플랫폼 연결 시도와 제한, 태블릿 네트워크 및 앱 제어 조사, UNIST 학생 시나리오와 검증 결과.

## 검증된 범위와 제약

학교 게시판 검색·선택·본문, 예비수강신청 표시 기간, 메일 테스트 초안의 특정 실기기 시나리오를 확인했다. 이미지로만 된 공지는 이미지 내용 미확인으로 반환한다. Android 앱 빌드와 태블릿 설치, 검색 관련 실제 채팅 계측 시험 및 기존 채팅 작업 테스트 기록은 아래 문서에 있다.

현재 학교 작업은 PC의 로컬 중계, USB/ADB 연결, 기존 로그인 WebView와 Qwen 서비스에 의존한다. 공지 감시는 세 게시판의 첫 페이지만 주기적으로 확인한다. 기기 단독 지속 실행·모든 공고와 메일에 대한 정확한 개인화·학교 원본 HWP 양식 작성·코레일 열차 결과와 예약·외부 시나리오 전체 연동은 완성되지 않았다. 학교 로그인 세션을 보유한 기존 앱의 팝업 수정본 적용도 검증되지 않았다.

- `NUBI_UNIST_INTEGRATION_GOALS.md`: 학생 시나리오와 외부 서비스 연결 목표 및 기록.
