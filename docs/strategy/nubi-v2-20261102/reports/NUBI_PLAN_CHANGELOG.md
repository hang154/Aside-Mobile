# NUBI v2.0 — Change Log vs. Submitted 23-Slide Draft

## 18. 이번 개정 변경 이력

- **수익모델:** 기존 9,900원/19,900원·유료 전환율 4%·무료 사용자 월 180원 가정 모델 삭제. 무료 구독 0원·광고/CPS/CPA 중심으로 교체.
- **손익분기:** 기존 132,043 MAU는 유료전환 가정이므로 폐기. 광고·거래 ARPU 및 완전 변동원가에 따른 보수·기준·낙관 민감도로 재설계.
- **비전:** 대학생용 AI 앱이 아니라 대중 무료 개인 에이전트라는 확장과 첫 진입 전략을 명확히 분리.
- **홈 UI:** 상황 배너/목적 에이전트/긴급 작업/광고 분리의 명확한 우선순위 추가.
- **차별화:** 모델 성능 점수보다 채팅 명령→홈 결과→모바일 실실행 증명으로 이동.
- **성장:** 효도쿠폰을 무료 AI 체험권에서 상점 혜택·가족 온보딩으로 재해석. 농촌 할머니의 현금·기차·쿠폰 사용 사례를 정식 창업 서사로 반영.
- **광고:** 광고를 알아차리지 못하게 숨기는 방식 대신, 적격한 구매 순간에 명시적 표시와 실제 경제적 효용을 제공하는 목적 기반 제안으로 설계.
- **기술:** 0.6.13 GitHub 실기기 검증과 전체 미완료 기능을 분리. Play 접근성 정책·학교윤리·실제예약/결제 리스크를 공개.
