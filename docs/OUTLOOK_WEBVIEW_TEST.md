# Outlook 웹 접근 시험

## 2026-10-31 실기기 결과

- `ai.decisionos.nubi.unistlive` WebView에서 Microsoft Outlook 웹 주소를 열고 사용자가 직접 로그인했다. 이후 Outlook 메일함 화면과 받은편지함 UI가 표시되는 것을 확인했다.
- 누비의 `화면 관찰`은 30개 항목을 반환했고 `항목 선택` 목록이 열렸다. 반환 항목은 최대 30개이며, 이번 목록에는 받은편지함 항목이 나타나지 않았다. 메일 읽기·분류·발송·삭제는 검증하거나 수행하지 않았다.
- 메일 주소·메일 제목·본문·인증 정보를 기록하지 않았으며 로그인과 로그인 후 화면을 녹화하지 않았다. 테스트 임시 UI 덤프는 제거했다.
- 이 결과는 기기 내부 WebView의 웹 세션이 열렸다는 뜻이다. OAuth/Graph 연동, 계정 연결 관리, 백그라운드 접근, 에이전트의 이메일 처리 또는 다른 앱과의 SSO는 구현하거나 검증하지 않았다. WebView 세션이 얼마나 유지되는지도 미검증이다.
