## 이번 지도·코레일 연결의 범위

- 홈에서 사용자가 검색어를 입력하고 네이버 지도 또는 카카오맵 검색 URL을 연다. 입력값은 URL 인코딩하고 빈 값·150자 초과를 차단한다. 이는 웹으로 연결하는 기능이며 지도 API에서 결과를 수집·비교하는 기능은 아니다.
- 코레일 공식 승차권 웹을 연다. 날짜·역·인원 입력, 좌석 검색, 로그인, 결제, 예약 확인은 코레일에서 사용자가 직접 수행한다. WebView 호환성이나 로그인·예약 성공은 실기기 시험 결과로 별도 표기한다.
- 다음 단계의 카카오맵 REST 장소 검색은 개발자 앱 등록·키와 쿼터, 네이버 지도는 제공 API별 등록·인증 및 사용 조건이 필요하다. 코레일은 공개 예약 API 사용 권한과 데이터 계약을 먼저 확인하며 확인되지 않은 비공식 API를 공식 연동이라고 부르지 않는다.
- 지도 후보 비교에는 장소 식별자, 명칭, 주소, 좌표, 조회 시각, 출처 URL과 최신성 실패 상태를 보존한다. 영업 여부·후기·가격의 제공 범위는 각각 공급자 정책과 데이터에서 확인한다. 서로 다른 공급자의 결과가 같은 장소인지 불확실하면 합치지 않는다.
- 코레일 흐름은 출발·도착·날짜·인원을 사용자에게 확인하고 검색 결과의 열차·출발·도착·요금·좌석 상태·조회 시각을 제시한 뒤, 실제 사이트의 예약·결제 및 완료 화면을 확인할 때만 완료라고 표시한다. 로그인·CAPTCHA·본인인증은 사용자가 처리한다.

## 실기기 시험 기준

1. 각 지도 버튼의 정확한 검색어 전달, 한글·공백 인코딩, 빈 값 차단 및 검색 결과 화면을 각각 확인한다. 서비스가 WebView를 거부하면 오류와 대체 브라우저 사용 경로를 확인한다.
2. 코레일 승차권 화면 접근 및 검색 화면 표시를 확인하고 실제 출발·도착·날짜는 사용자에게 받아 검증한다. 예약 및 결제를 하지 않았으면 미검증으로 남긴다.
3. 로그인이 필요한 화면과 개인 메일은 녹화하지 않는다. 실기기 영상은 로컬에만 둔다.
4. 공식 출처 및 API 문서: [카카오맵 REST API](https://developers.kakao.com/docs/ko/kakaomap/rest-api), [네이버 Maps 개요](https://api.ncloud-docs.com/docs/ainaverapi-maps-overview), [코레일 승차권](https://www.korail.com/ticket), [코레일 FAQ](https://www.korail.go.kr/ticket/reserve/guide/faq).

## 0.1.5 실기기 검증 기록

- Lenovo 태블릿 `ai.decisionos.nubi.travelpilot`에 별도 설치. 빌드 CI `41156206670`, APK SHA-256 `07f87cb3e3bb9fc9b4516104c9c5cb5a947a8b8a8e486f560509b6a8e56607fa`.
- 새 홈의 각 버튼으로 `UNIST`를 전달했다. 네이버 지도는 실제 검색 결과 목록, 코레일은 출발역·도착역·출발일·인원과 열차 조회 화면이 표시됐다. 코레일 열차 조회·예매·결제는 수행하지 않았다.
- 카카오맵은 검색어가 전달된 앱/웹 선택 중간 화면까지 확인했다. '설치없이 지도보기' 선택 후 웹 검색 주소로 이동하는 것은 확인했으나, 결과 목록은 검증하지 못했다.
- 같은 기기의 열린 화면을 OpenCLI와 stdio MCP를 통해 읽었다. 네이버·카카오·코레일 각각 예상 도메인과 화면 표식이 반환됐다. 이는 상태 확인이며 장소 데이터 추출과 예약 API가 아니다. ADB 포워딩은 시험 후 제거했다.

## 2026-10-31 MCP 실제 조회 확장

- `nubi_naver_search`와 `nubi_kakao_search`는 검색어를 받아 기기 브라우저에서 검색하고 장소명·분류·주소·출처를 반환한다. UNIST 검색으로 MCP 경유 네이버 9건, 카카오 15건을 확인했다. 지도별 데이터 출처와 노출 수가 달라 순서나 동일 장소 여부를 단정하지 않는다.
- `nubi_unist_calendar`는 공개 공식 일정 60일을 조회해 10건을 반환했고, `nubi_papers_search`는 OpenCLI arXiv 검색의 제목·저자·날짜·원문 10건을 반환했다. 공지·학식·채용·동아리·친구 조율·메일의 전용 조회는 이 시험 범위에 없다.
- 코레일의 기본 서울→부산 열차 조회 요청은 `-8002` 자동화/개발자도구 접근 제한 안내가 표시됐다. `nubi_korail_options`는 이 제한을 보고하며 열차 결과 추출은 아직 실제 결과로 검증되지 않았다. 공식 제휴/API 및 일반 브라우저 방식 확인이 필요하다.
- 기존 OpenCLI 네이버 쇼핑 검색은 태블릿 WebView에서 검색 입력 요소를 찾지 못해 실패했다. 상품 비교를 완성했다고 주장하지 않는다. API 등록 및 서비스 접근 조건이 필요하다.
- 도구는 개발 PC의 로컬 MCP와 USB 디버깅 세션에서 실행된다. 누비 APK에 원격 MCP 실행기나 선택지 표시 화면을 탑재한 것은 아니다. 테스트 후 ADB 포워딩을 제거한다.
- 축제·데이트 준비용 `nubi_weather_forecast`를 OpenCLI wttr 예보에 연결하고 `Ulsan` 3일 결과를 MCP로 확인했다. 요청 위치는 표시하지만 공급자가 해석한 실제 지점은 결과에서 별도 검증하지 못했다.

## 2026-10-31 선택 시나리오 추가 검증

- 채용: UNIST 인공지능대학원 첫 페이지 10건, 첫 번째 선택 공고 본문과 접수기한을 조회했다. 제목·순서가 일치하지 않으면 거절한다. 목록에는 마감된 공고도 있으므로 현재 모집 중이라고 단정하지 않는다.
- 쇼핑: 태블릿 네이버 모바일 가격비교의 초콜릿 결과 10건, 선택 항목의 표시 가격과 배송비·광고 여부를 확인했다. 가격·배송비·쿠폰·회원 조건은 변동될 수 있다. 선택 후 주문이나 상품 상세 이동은 미구현이다. 네이버의 옛 쇼핑 검색 API는 종료됐으며 이 구현은 모바일 웹 화면을 읽는다.
- 식당: UNIST 공식 사이트의 식당 3곳 위치·운영시간. 오늘 식단 메뉴는 미구현이며 과거 공개된 밥먹어U Heroku 주소는 더 이상 운영되지 않음을 확인했다.
- 동아리: UNIST 컴퓨터공학과 공식 소개 1건과 원문. 전체 중앙 동아리와 모집 현황은 미구현이다.
- 선택한 공고·상품·식당·동아리를 PC 로컬 MCP 저장소에 기록하고 다시 조회하는 네 흐름을 시험했다. 안드로이드 앱의 할 일 DB와는 별도다.
- 메일: 이전 세션에서 연결된 Outlook 도구를 통한 열람은 확인했지만 누비 앱이나 이 로컬 MCP 자체에 Outlook 인증·메일 읽기 API를 제공하는 기능은 아직 없다. 코레일 제한 `-8002`는 유지되어 열차 결과 조회는 미완료다.

## 2026-10-31 외부 채용 플랫폼 연동

- 사람인: 태블릿 누비 WebView에서 검색어 `데이터 분석 인턴`으로 20개를 조회하고 첫 공고의 상세 핵심 정보와 선택 저장·재조회를 MCP로 시험했다. 상세 요강 이미지·iframe의 내용까지 읽었다고 보장하지 않는다.
- 원티드: `데이터 분석`의 검색·관련 추천 12개를 조회하고 선택 공고 본문과 저장·재조회를 MCP로 시험했다. 추천은 검색어와 직접적으로 일치하지 않을 수 있다.
- 두 연결은 공식 API가 아닌 로그인 없이 표시된 웹 DOM 기반이며 UI 변경·접속 제한에 취약하다. 사람인의 공식 채용검색 API는 별도 사용 신청·승인과 access key가 필요하다: https://oapi.saramin.co.kr/guide/info
- 앱 내부에 MCP 통합 UI를 탑재하거나 실제 입사 지원을 진행한 것은 아니다. 결과 저장은 PC의 로컬 MCP 저장소다.
