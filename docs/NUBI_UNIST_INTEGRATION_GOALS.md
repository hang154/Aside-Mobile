## 이번 지도·코레일 연결의 범위

- 홈에서 사용자가 검색어를 입력하고 네이버 지도 또는 카카오맵 검색 URL을 연다. 입력값은 URL 인코딩하고 빈 값·150자 초과를 차단한다. 이는 웹으로 연결하는 기능이며 지도 API에서 결과를 수집·비교하는 기능은 아니다.
- 코레일 공식 승차권 웹을 연다. 날짜·역·인원 입력, 좌석 검색, 로그인, 결제, 예약 확인은 코레일에서 사용자가 직접 수행한다. WebView 호환성이나 로그인·예약 성공은 실기기 시험 결과로 별도 표기한다.
- 다음 단계의 카카오맵 REST 장소 검색은 개발자 앱 등록·키와 쿼터, 네이버 지도는 제공 API별 등록·인증 및 사용 조건이 필요하다. 코레일은 공개 예약 API 사용 권한과 데이터 계약을 먼저 확인하며 확인되지 않은 비공식 API를 공식 연동이라고 부르지 않는다.
- 지도 후보 비교에는 장소 식별자, 명칭, 주소, 좌표, 조회 시각, 출처 URL과 최신성 실패 상태를 보존한다. 영업 여부·후기·가격의 제공 범위는 각각 공급자 정책과 데이터에서 확인한다. 서로 다른 공급자의 결과가 같은 장소인지 불확실하면 합치지 않는다.
- 코레일 흐름은 출발·도착·날짜·인원을 사용자에게 확인하고 검색 결과의 열차·출발·도착·요금·좌석 상태·조회 시각을 제시한 뒤, 실제 사이트의 예약·결제 및 완료 화면을 확인할 때만 완료라고 표시한다. 로그인·CAPTCHA·본인인증은 사용자가 처리한다.

## 실기기 시험 기준

1. 각 지도 버튼의 정확한 검색어 전달, 한글·공백 인코딩, 빈 값 차단 및 검색 결과 화면을 각각 확인한다. 서비스가 WebView를 거부하면 오류와 대체 브라우저 사용 경로를 확인한다.
2. 코레일 승차권 화면 접근 및 검색 화면 표시를 확인하고 실제 출발·도착·날짜는 사용자에게 받아 검증한다. 예약 및 결제를 하지 않았으면 미검증으로 남긴다.
3. 로그인이 필요한 화면과 개인 메일은 녹화하지 않는다. 실기기 영상은 로컬에만 둔다.
4. 공식 출처 및 API 문서: [카카오맵 REST API](https://developers.kakao.com/docs/ko/kakaomap/rest-api), [네이버 Maps 개요](https://api.ncloud-docs.com/docs/ainaverapi-maps-overview), [코레일 승차권](https://www.korail.com/ticket), [코레일 FAQ](https://www.korail.go.kr/ticket/reserve/guide/faq).
