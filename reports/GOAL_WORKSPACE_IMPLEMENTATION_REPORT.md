# 누비 목표 워크스페이스 구현·배포 검증

실행일: 2026-10-31, Asia/Seoul. 운영 서비스 공개 출시가 아닌 비공개 개발 APK 배포다. 첨부 기획의 모든 기능이 완료된 상태는 아니다.

## 실제 변경

운동 건강이·연애 다정이·학점 똑똑이·집 사기 차곡이가 동일한 네이티브 홈, 워크스페이스, GoalStore/TaskStore와 브라우저 실행기를 사용한다. 취업·여행도 같은 형식이다. 캐릭터 프리셋과 개별 목표 UUID를 구분하고 여러 목표의 콘텐츠·준비물·일정·프로필·구매 초안을 분리한다. 미디어 기본 탭 및 마지막 탭 복원, 목표 수정·삭제를 제공한다.

목표 → 실제 뉴스/영상 → 출처를 가진 콘텐츠 → 사용자가 확인한 Need → 상품 대체 후보 → 구매 초안 확인 → 정확한 HTTPS 판매처 상품 → 같은 목표로 복귀하는 경로를 연결했다. 모임은 공개 외부 후보 조회이며 누비 이용자 매칭은 빈 상태다. 구매·결제를 실행하거나 웹 이동을 검증 구매로 세지 않는다. 일반 실행에는 PC·ADB·MCP·접근성 권한이 필요 없다.

Finch의 목표·캐릭터 중심 홈, Habitica의 아바타·행동 목록 및 Android 내비게이션 지침을 참고했다. 원본 이미지·아이콘을 복제하지 않고 Canvas로 네 색 캐릭터를 직접 그렸다. 근거 링크는 요구사항 문서에 있다. 기존 캠퍼스 도구는 별도 Activity로 보존하고 v1 할 일 DB를 비파괴 마이그레이션했다.

## 실기기 탐색

Lenovo Android 16 ARM64 태블릿, 가로 2944×1840에서 새 목표를 생성하고 목표 제목을 매번 확인했다. 네 목표 모두 뉴스·영상·목표 일정 저장·공개 모임·상품을 실제로 탐색했다. 공개 결과 수는 실행 시점의 관측값이며 사용자 성과나 추천 품질 지표가 아니다.

- 운동: 뉴스 15 / YouTube 13 / 문토 공개 후보 2 / 11번가 후보 19.
- 연애: 뉴스 15 / YouTube 20 / 문토 공개 후보 6 / 11번가 후보 20.
- 학점: 뉴스 15 / YouTube 16 / 문토 공개 후보 4 / 11번가 후보 18.
- 집 사기: 뉴스 15 / YouTube 20 / 문토 공개 후보 1 / 11번가 후보 18.

문토는 공개 추천 목록에서 목표 단어로 거른 결과다. 지역·모집 상태·실제 매칭을 검증하지 않았다. 뉴스·영상은 제목·메타데이터를 읽었으며 전체 내용을 분석한 것이 아니다. 집 사기에서도 가계부 등 목표 준비물을 탐색했으며 부동산 자체를 일반 쇼핑 상품으로 취급하지 않았다.

운동 준비물 선택 후 11번가 상품 ID 5741335330의 정확한 HTTPS 상품 화면으로 이동했다. 검색 표시가와 배송비를 읽어도 옵션·최종 총액은 미검증으로 유지한다. 상품 수량·조건을 확정하거나 구매 버튼을 누르지 않았다. 네이버쇼핑은 새 세션에서 auth_required였다.

청약홈 공식 화면 접속은 확인했다. 네이버 부동산은 검색어 경로와 좌표 경로 모두 서울 기본 지도로 바뀌었다. 성공으로 세지 않고 직접 지도 연결을 제거한 뒤 울산 아파트 공개 웹 검색으로 대체했다. 직접 매물 구조화 조회는 미완료다.

## 자동 검사 및 실행 범위

기존 파서 17, 행동 13, 콘서트 6, 캠퍼스 17 = 53개 통과. 새 목표·URL·오퍼·승인 규칙 90개, 고정 DOM 추출기 계약 14개 통과. 실제 Android DB 검사는 15개 통과했다. 개별 검사 합계 172개이며 계약 fixture와 라이브 탐색을 구별한다. 정적 보안·수집 경계·일반 Manifest 검사 3종도 통과했다.

DB 검사는 서로 다른 목표 격리, 레코드 소유권 재지정 거부, 공개 프로필 기본 비공개, 삭제 cascade, 실제 v1 DB의 기존 ID·제목 보존과 v2 일정 공존을 포함한다. 순수 로직의 승인 유효시간·가격 버전 검사는 실제 주문 API E2E가 아니다.

Gradle debug / androidTest / unsigned release 빌드가 통과했다. 최종 변경 후 영향받는 90개 규칙·14개 추출기·보안 검사를 다시 통과하고 APK를 재빌드했다. 변경하지 않은 네 목표 E2E 결과는 재사용했다. 초기 구현 커밋 70545d26fc8f8eac51aff53da735c195796d775c의 GitHub Actions 41175818939는 성공했다. 이후 수정의 CI 결과는 해당 커밋의 Actions 기록을 확인한다.

태블릿 가로, 뒤로 가기, 목표 재진입 및 앱 강제 종료 후 복원을 확인했다. 작은 휴대폰·큰 글꼴·회전 중 복원·네트워크 단절은 미실행이다. 두 계정 서버 커뮤니티 테스트도 서버가 없어 미실행이다. 기기의 다른 앱 접근성 서비스는 보존했고 새 APK의 패키징된 Manifest에 service가 없음을 확인했다. PC가 물리적으로 분리된 장시간 운용 시험은 하지 않았으며 핵심 경로에 개발 PC 네트워크 호출이 없음을 코드로 확인했다.

초기 화면 자동화의 exit137과 잘못된 목표 카드 선택 실행은 성공에서 제외했다. 프로세스별 XML과 새 목표 생성·제목 확인으로 보정한 fresh-final 결과를 최종 근거로 사용한다. 모든 예외를 앱 정상 동작으로 간주하지 않는다.

동시 진행 중인 BrowserWorkspaceActivity/RemoteBrowserRelay/AsideAccessibilityService/OpenCLI 변경을 포함하지 않도록 기준 8d6871e의 앱과 이번 소유 파일 23개를 고정한 별도 로컬 디렉터리에서 빌드했다. 공유 저장소의 다른 변경은 보존했다. 고정 소스의 소유 파일 해시와 작업 트리의 소유 파일이 일치하며 제외한 두 Java 파일은 기준 커밋과 일치함을 확인했다. 따라서 공유 작업 트리 전체의 HEAD만으로 APK 전 소스가 설명된다고 해석하지 않는다. 로컬 frozen-inputs.json에 전체 선택 입력과 제외 범위를 기록했다. 실행 절차는 docs/GOAL_WORKSPACE_RUNBOOK.md다.

reports/goal-workspace의 해시 JSON·CSV 3개는 scripts/verify_goal_artifacts.py로 재생성한다. byte 동일성은 기능 검증을 대신하지 않는다. 비밀값·실사용자 세션·캡처·영상은 커밋하지 않는다.

## 남은 기능과 외부 조건

두 판매처의 동일 상품·옵션·최종 총액을 확인한 통합 최저가 비교는 미완료다. 11번가 여러 상품을 여러 플랫폼 비교로 세지 않는다. 쿠팡 추출기는 계약/연결 수준이고 토스쇼핑 소비자 조회·주문 경로는 없다. 강의·전문가의 동일 범위 가격 비교도 미완료다.

누비 다중 사용자 서버·실시간 매칭·DM·신고, 자동 가격 감시·푸시, 두 계정 권한 검증은 미구현이다. 알림 조건은 기본 OFF·manual_only다. 프로필은 로컬 초안이고 공개되지 않는다.

YouTube 공식 API 키, Threads 토큰·심사, Instagram 권한은 확보하지 않았다. 실제 YouTube 실행 경로는 공개 WebView다. 검색 계획·관련성 판정은 규칙 기반이며 LLM 추론으로 표시하지 않는다. 기존 메일 읽기·코레일 예약의 제한도 유지한다. 이 상태를 전체 기획 완성·운영 출시로 보고하지 않는다.
