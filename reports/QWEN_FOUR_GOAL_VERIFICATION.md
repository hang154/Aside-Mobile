운동·연애·학점·집 사기 모두 Qwen이 검색어를 결정하고 실제 태블릿 WebView에서 상품·공개 모임·영상 후보를 읽고, 영상 원문을 선택해 제목을 확인한 뒤 각 목표에 한국어 요약을 저장했다. 모든 성공 실행은 같은 0.2.2 APK를 사용했다.

모델 요청과 모든 응답의 모델 ID는 `Qwen3.8-27B-abliterated-AWQ-W4A16`으로 일치했다. 모델은 연결된 서버에서 실행됐으며, 브라우저 명령은 stdio MCP → 인증된 HTTPS 중계 → 태블릿으로 전달했다. USB는 설치·페어링 화면 입력·캡처·사후 저장 검증에 사용했다. 실제 검색·선택·관측 명령에 ADB 포워딩을 사용하지 않았다.

각 실행에서 Qwen이 호출한 MCP 도구는 `nubi_goal_explore → nubi_goal_select → nubi_goal_observe → nubi_goal_report`이다. explore는 실제 goal_open/search/observe를 순차 수행하며 결과를 모델에 반환한다. 목표 ID와 최신 observation_id로 선택을 묶고, 보고서 출처는 해당 목표에서 관측한 URL만 허용한다.

네 보고서의 목표 ID는 모두 달랐다. 앱 강제 종료 후 저장소를 읽어 각 보고서의 요약·출처·모델 ID가 Qwen이 전달한 값과 일치함을 확인했다. 이후 네 작업실에서 각각의 요약이 표시되는 것도 확인했다. 전경 탐색 화면을 닫은 뒤에는 원격 명령이 실행되지 않고 25초 제한으로 종료됐다.

## 재현과 관측한 제한

- 실행은 [연결 문서](../docs/QWEN_GOAL_BROWSER.md)의 `--goal fitness|love|grades|home` 명령을 순차 사용한다. 브라우저는 하나이며 병렬 탐색하지 않는다.
- 초기에는 태블릿과 다른 네트워크 대역을 사용해 연결이 실패했다. 태블릿 Wi-Fi에서 접근 가능한 호스트 주소로 수정했다.
- YouTube www → 모바일 원문 전환이 거부되는 결함을 재현해 같은 영상 ID의 전환을 허용했다. 네 성공 실행에서 원문 제목 읽기를 확인했다.
- 초기 모델 요청 시간 초과를 관측했다. 모델 요청을 줄이는 묶음 탐색과 최대 한 번의 모델 시간 초과 재시도를 넣었다. 성공한 운동 실행에서도 모델 시간 초과 한 번 뒤 재시도를 관측했다. 즉시 응답 성능을 보장하는 단계는 아니다.
- 실행기를 단계적으로 개선했다. 실제 목표 주제를 읽는 호스트 bootstrap은 연애·학점·집 사기에서, 보고서 저장 응답을 종료 조건으로 삼는 흐름은 학점·집 사기에서 검증했다. 네 성공 실행의 앱·검색·선택·저장 도구 계약은 동일하다.
- 조회 결과는 공개 DOM 메타데이터이다. 영상 내용 분석·시청 완료, 최종 구매 가격 검증, 구매·결제·로그인·모임 가입을 검증한 것이 아니다.
- 문토는 공개 추천 카드의 목표 단어 필터이다. 울산 검색에서도 다른 지역 카드가 나왔고 집 사기에서도 일반 재테크 모임이 나왔다. 지역·전문성·모집 상태를 확인한 실시간 매칭으로 해석하지 않는다.
- 집 사기는 주택 청약 관련 영상·가계부·공개 모임 탐색 범위다. 실매물·금융상품 계약 조회까지 제공하지 않는다.
- 앱을 벗어나면 연결이 종료된다. 실행 종료 후 임시 중계와 인증키를 정리하고 테스트 중 바꾼 USB 충전 시 화면 유지 설정을 원래 값으로 복원했다.
