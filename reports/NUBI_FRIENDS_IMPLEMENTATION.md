# 누비 계정 간 친구 제안 구현

사용자 요청에 따라 통화 사업자 계정 없이 먼저 친구 계정을 연결하는 흐름을 구현했다. Pickle의 친구 페이지에서 연결 후 에이전트끼리 약속·모임을 조율한다는 안내를 확인했다. Pickle의 내부 API나 계정 간 프로토콜은 사용하지 않는다.

## 구현 범위

- 누비 친구 계정 생성. Android Keystore AES-GCM으로 계정 키 저장.
- 10분 만료·1회용 초대 코드로 상호 연결.
- Qwen3.8-27B-abliterated-AWQ-W4A16이 사용자 요청으로 제안 초안을 생성.
- 사용자가 초안을 확인하고 전송하면 친구 계정에 실제 전달.
- 수신자가 수락/거절하고 송신자가 상태 확인.
- SQLite 지속 저장, 계정 인증, 연결 관계 검사, 메시지 중복 전송 방지.
- 기존 목적별 누비와 별도로 친구 탭 추가.

## 검증

`python3 opencli-nubi/test-friends.py`: 8개 검사 통과. 인증 위조, 자기 초대, 만료, 초대 재사용, 미연결 전송, 수신자 권한, 동시 중복 전송, 재시작 지속성과 연결 해제를 포함한다.

실제 운영 중인 HTTPS 릴레이에서 테스트 계정 두 개로 연결 → 실제 Qwen 초안 생성 → 전송 → 상대 조회 → 수락 → 송신자 상태 확인을 수행했다. 모델 반환 식별자는 요청 모델과 일치했다. 실사용자에게 메시지를 보내지 않았다. 테스트 계정과 메시지는 검증 후 삭제했다.

실행 결과와 화면 캡처는 로컬 `nubi-friends-verification`에만 보관한다.

## 범위와 남은 작업

이 기능은 누비 계정끼리 동작한다. Pickle 계정과의 직접 상호 운용은 구현하지 않았다. 현재 초안과 전송은 친구 화면에서 명시적으로 요청하며, Qwen이 받은 메시지에 자동으로 답하거나 실제 상대 캘린더를 조회하지 않는다. 새 메시지는 친구 탭 재진입으로 조회하며 푸시 알림은 없다. 단일 연구용 릴레이 페어링이 있는 기기끼리의 실험으로, 공개 가입·인증 복구·악용 방어를 갖춘 서비스 출시 상태는 아니다.

실제 AI 전화, 결제 사업자 연결, 모든 외부 서비스의 실행 기능은 이번 친구 연결 구현에 포함되지 않는다. 기존 문서 관련 미커밋 수정은 보존했다.
