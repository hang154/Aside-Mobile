# 누비 0.3.2 반응형 UI 검증

## 결과

실기기의 Pickle 앱을 열어 태블릿 가로·세로, 508dp 화면의 채팅·친구·둘러보기·보관함을 관찰하고 화면 구성과 색을 실측했다. 누비 네이티브 UI를 이에 맞춰 재구성하고 태블릿에 설치했다. 바이너리 코드·그림을 복사한 구현이 아니라 실제 화면과 동작을 바탕으로 만든 누비 구현이다.

## 변경 사항

- 태블릿 300dp 고정 사이드바와 흰 배경, 회색 선택 표시.
- 좁은 창에서는 아이콘만 있는 하단 탐색과 왼쪽 메뉴 드로어.
- 상단 원형 캐릭터, 이름 선택, 목적 선택 버튼. 누비의 네 목적과 대화를 유지한다.
- #F4F4F4 말풍선과 #EAEAEA 입력창, 줄 간격·둥근 모서리·전송 버튼 비율 수정.
- 말풍선은 내용 크기와 실제 창 너비에 맞추고 최대 460dp로 제한한다.
- 둘러보기는 아이콘·제목·설명·구분선 목록. 보관함은 세그먼트, 중앙 빈 상태, 오른쪽 아래 추가 버튼.
- 창 크기 및 회전 변경 시 활동과 WebView를 유지한다. 초안도 유지한다.
- 상태 표시줄·내비게이션 inset 처리, 키보드 노출 시 하단 메뉴 숨김.
- 130% 글씨에서 목적 버튼의 글자 잘림 수정.

## 검증

분리된 빌드 폴더에서 빌드 성공. 기본 글씨와 130% 글씨 각각에서 65개 실제 창 크기/탐색/경계 검사를 통과했다. 휴대폰 크기는 동일한 태블릿의 디스플레이 크기 설정으로 검증했으며 별도 휴대폰 하드웨어 검증을 뜻하지 않는다.

검증 폭은 360dp, 508dp, 태블릿 세로 865dp, 가로 1385dp이다. 각 조건에서 사이드바·하단 메뉴 표시, 입력창 경계, 말풍선 경계, 목적 버튼 글자 폭·높이, 초안과 활동 유지, 둘러보기·보관함 전환을 확인했다. 360dp에서 드로어 및 실제 키보드 화면도 캡처했다.

기존 네이티브 데이터·화면 흐름 62개 통과. 목표 규칙 90개와 보안 정적 검사 2종 통과. git diff 공백 검사 통과. 초기 실측 과정에서 화면 종류 변경 시 활동 재생성을 재현하고 manifest의 screenLayout 처리와 창 너비 갱신을 수정했다. 큰 글씨의 목적 버튼 잘림은 캡처 검수로 찾아 수정하고 회귀 검사에 추가했다.

캡처는 탐색 직후 프레임이 그려질 때까지 대기한 뒤 저장한다. 시험용 목표는 삭제했고 해상도·글씨 크기·자동 회전 설정을 원래대로 복구했다. 참고 화면과 실행 캡처는 로컬에만 저장한다.
