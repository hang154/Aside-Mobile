# 누비 작업공간 UI 0.2.5 검증

2026-11-01, Lenovo 태블릿 HA263Q91 / Android 16. 앱 ID `ai.decisionos.nubi.travelpilot.goals`, versionCode 24, versionName `0.2.5-workspace`.

## 변경 결과

assistant-ui의 메시지·입력·도구 그룹 구성과 OpenBot의 에이전트별 작업공간 구성을 현재 Java Android 앱에 적용했다. 새 UI와 기존 OpenMuse 참고 UI를 선택할 수 있다. 원본 React 패키지·OpenBot 서버·AG-UI 런타임을 설치한 것으로 주장하지 않는다. 참고 소스와 확인한 MIT 라이선스 범위는 `docs/ASSISTANT_OPENBOT_WORKSPACE.md`에 기록했다.

새 화면에는 목표별 대화 선택, 네 캐릭터 전환, 추천 질문 입력, 답변 복사·요청 수정, 실제 브라우저·실행 기록·파일 탭이 있다. 서버 progress 배열을 완료 답변에 보관한다. 파일 목록은 현재 목표의 chatMessages.document에 들어 있는 DOCX/HWPX만 모으며 기존 다운로드 인증·SHA256 검증을 재사용한다. 문서 결과를 일반 탐색 성공으로 잘못 표시하던 문구도 구분했다.

검증 과정에서 삭제된 목표의 Activity가 늦게 pause되며 저장을 시도하는 오류를 발견했다. 삭제된 목표의 저장을 건너뛰도록 수정했고, 목표가 재생성되지 않는 회귀 검사를 추가했다. 검사 정리 단계에서 같은 fixture를 두 번 삭제하던 테스트 오류도 수정했다.

## 최종 APK의 실제 Qwen 탐색

사용자 입력 → 네이티브 전송 버튼 → HTTPS 중계 자동 worker → 실제 Qwen → MCP → 태블릿 WebView → 목표별 답변 저장을 네 번 실행했다. 모두 검색 결과 후보 2건, 첫 후보 원문 열기·페이지 제목 관측, 실제 출처 2개와 실행 기록 4단계 저장을 확인했다.

- 운동: 유튜브 초보 스트레칭 후보. 35.5초, 완료.
- 연애: 부산 우천 실내 데이트 공개 글. 35.5초, 완료.
- 학점: 파이썬 입문 학습 자료 공개 글. 35.3초, 완료.
- 집 사기: 유튜브 내 집 마련 준비 후보. 55.5초, 완료.

최종 추적 파일에서 네 작업 모두 `completed=true`, 실제 응답 모델 `Qwen3.8-27B-abliterated-AWQ-W4A16`을 확인했다. 후보 내용 전체·영상 시청·실제 방문 적합성까지 검증한 것은 아니다. 이전 가격 2만원 이하 가계부 쇼핑 시나리오 실패를 해결했다는 의미도 아니다.

## 실제 화면 조작

학점 대화에서 실행 기록, 실제 DOCX/HWPX 파일 목록, 목표별 대화 선택창을 확인했다. 기존 화면으로 바꾼 뒤 새 작업공간으로 돌아와 기록과 파일이 유지되는 것도 확인했다. 파일 탭의 다운로드·열기로 해시 검증을 거친 문서가 Android 앱 선택창(ReadEra 포함)에 전달되는 것을 확인했다. 문서 전체 레이아웃을 새로 검수했다는 뜻은 아니다.

화면 전환 소개 영상 약 58초와 캡처는 로컬 `verification-final/`에만 저장했다. 보조 UI 검사에서 다운로드 직후 선택창을 너무 일찍 검사한 첫 시도는 실패했고, 비동기 다운로드가 끝난 뒤 실제 선택창을 다시 확인해 통과했다. 앱 구현 변경은 필요하지 않았다.
