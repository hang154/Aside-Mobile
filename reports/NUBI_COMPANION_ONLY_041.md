# 누비 0.4.1 — 0.3.2 화면 안으로 기능 이관

요구사항: 0.3.2의 캐릭터 헤더·사이드바·좁은 화면 드로어/하단 메뉴·대화·둘러보기·보관함을 유일한 앱 셸로 사용한다. 구형 화면을 별도 Activity로 열거나 색상만 바꿔 감싸는 방식을 제거한다.

## 구현

- `GoalChatUi`의 Assistant/OpenBot/OpenMuse 화면 생성 경로와 화면 선택기를 제거했다. 기존 표시 설정 값으로 옛 화면을 다시 켤 수 없다.
- `NubiApplication`의 구형 Activity를 감싸던 공통 헤더 처리를 제거했다.
- 기존 화면 클래스 12개는 화면 생성 코드가 없는 호환 진입점으로 변경했다. manifest의 기존 컴포넌트 14개는 `CompanionEntryActivity` 별칭으로 연결되며, 새 `GoalAgentActivity` 셸로 진입한다.
- 캠퍼스·학사일정·할 일·공연 여행·생활 계획·관심 앱·로컬 모델·로컬 제안·수집 설정·수동 브라우저는 `CompanionPanel` 안에 표시한다. 중복 브랜드 제목, 구형 내비게이션과 버튼 그림자를 제거하고 0.3.2 입력창·버튼 스타일을 사용한다. 큰 글씨는 입력창과 버튼 높이가 내용에 따라 늘어난다.
- 목표 미디어·준비물·구매 초안·수동 가격 조건·모임·일정·개인화는 `CompanionGoalTools`로 옮겼다. 기존 저장소와 취소/재개·조건 확인 로직을 유지한다.
- 수동 브라우저의 주소 입력·뒤로/앞으로·관찰·항목 선택·검색어 입력·팝업·파일 첨부·원격 연결을 새 셸 내부에서 실행한다. Qwen이 쓰는 목표 WebView도 같은 셸 안에 유지한다.
- 문서는 보관함/대화에서 다운로드 후 앱 안의 DOCX/HWPX 텍스트 미리보기로 연다. 표 서식 렌더링은 제공하지 않으며 원본 문서를 지원 앱에서 여는 선택도 유지한다. ZIP/XML 읽기 크기를 제한하고 외부 엔터티를 거부한다.
- 기능 패널을 오가도 입력 필드를 유지하며, 같은 앱의 GoalStore·TaskStore·설정·쿠키·친구 계정과 Keystore 데이터를 초기화하지 않는다.

## 사용 경로

`둘러보기 → 학교생활 / 생활 도구` 또는 `나의 누비 → 학교 메일·포털 / 생활 도구`에서 기능을 연다. 채팅·캐릭터·목적 선택·보관함은 0.3.2 방식 그대로다. 옛 바로가기와 수집 알림도 새 셸로 들어온다.

Android 권한 설정·파일 선택기·선택적으로 여는 문서 지원 앱은 OS/외부 앱 화면이다. 외부 웹사이트의 디자인은 해당 서비스가 제공한다. 포털 로그인·예약·결제·SharePoint 업로드 등 기존 미완료 서비스의 권한이나 서버 기능이 이번 UI 이관으로 새로 완성된 것은 아니다.

## 검증 기록

최종 실행 결과·캡처·APK는 로컬 `nubi-companion-only-release`에 보관한다. 캡처·계정·메일·문서 원문은 저장소에 넣지 않는다. 기존 다른 패키지를 삭제하거나 그 세션을 복사하지 않았다.

## 목적 중심 기능 통합

진입 경로는 `둘러보기 → 현재 누비의 기능` 또는 `나의 누비 → 현재 누비의 기능`이다. 하위 기능은 현재 goal_id를 유지한다. 기존 생활 도구 바로가기도 현재 에이전트의 기능 목록으로 연결된다.

- 건강이: 운동 영상·자료, 용품 비교, 운동 모임, 운동 일정, 시설·이동.
- 다정이: 관계·데이트 자료, 선물 비교, 취미 모임, 데이트 일정, 장소·이동, 여행·숙소 비교, 생활 계획.
- 똑똑이: 학습 자료, 준비물, 스터디, 학습 일정, 학교 메일·포털·공고, 학사일정, 문서 보관함, 학교 주변.
- 차곡이: 주거·청약 자료, 준비물 비교, 공부 모임, 청약·주거 일정, 지역 탐색, 주거 준비 계획.
- 기존 든든이: 취업·면접 자료, 면접 준비물, 취업 스터디, 지원 일정, 채용 공고, 지원 문서, 면접 장소.
- 기존 떠남이: 여행 자료, 준비물, 모임, 일정, 교통·숙소 비교, 여행 장소, 계획.

공통 도구에는 할 일·관심 앱·로컬 모델·로컬 제안·수집 설정·수동 브라우저를 유지했다. 장소·이동 화면은 목적별 초기 검색어를 제공하며 사용자가 수정할 수 있다. 네이버 지도·카카오맵·코레일은 앱 내 브라우저에서 연다. 이는 기능 진입점과 기존 동작의 통합이며 자동 예약이나 거래 완료를 뜻하지 않는다. 기존 취업·여행 목적은 새 목표 만들기와 목표별 대화로 계속 사용할 수 있다.
