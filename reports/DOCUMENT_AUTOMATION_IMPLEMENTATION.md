# 누비 문서 자동화 구현 및 검증 — 2026-11-01

## 판정

문서 작업 실행기·MCP·앱 채팅 연결·DOCX/HWPX 파일 전달을 구현했다. 실제 Outlook 메일/첨부를 가져와 Qwen이 작성한 L시리즈 초안을 앱 채팅에서 생성하고 태블릿에 내려받았다. 업로드까지의 실서비스 end-to-end는 미완료다. SharePoint 연결/쓰기 권한과 대상 폴더가 확정되지 않았고, 실제 제출용 자료에도 등록 계좌 전체/원화 정산/서명 확인이 남아 있다.

## 구현

- 현재 사용자 지시의 문서 키워드로 별도 문서 실행기를 자동 호출한다. 네 목표에서 같은 문서 포맷을 사용하고 결과는 해당 목표에 저장한다. 실제 문서 채팅 시험은 학점 목표에서 진행했다.
- Microsoft Graph 메일 검색·첨부 조회/다운로드 어댑터, 초기 메일 가져오기용 source_manifest, HWP5/DOCX/HWPX 텍스트 입력을 구현했다. 이번 실기기 시험은 연결된 Outlook 도구로 가져온 자료의 source_manifest를 썼다. 호스트 자체의 Graph 로그인·동적 메일 재조회가 검증된 것은 아니다.
- Qwen에 구조화된 도구 스키마를 제공해 필드·단가·수량마다 원문 구절을 인용하게 했다. 인용 구절 존재와 수치, 통화, 계좌 불일치, 누락을 검사하며 Decimal로 합계를 계산한다. 모든 사실의 의미적 정확성·지원 자격까지 보증하지 않는다.
- 공식 UIRP DOCX의 6개 표와 셀 구조를 유지한 작성 경로와 일반 L시리즈 예산/지원요청 문서를 구현했다. L시리즈 기존 HWPX의 모든 공식 레이아웃·그림·페이지 구성을 재현하지는 않는다. HWPX 생성은 가능하며 HWP5 바이너리 저장은 미지원이다.
- 문서 상태를 작성 초안/추가정보 필요/업로드 연결 필요/업로드 검증 완료로 구분한다. 등록 계좌, 원화 환산, 서명을 추정해 채우지 않는다. UIRP는 서명 확인 전 제출 가능한 상태로 표시하지 않는다.
- SharePoint는 서버 설정에 고정된 폴더에 새 업로드 세션을 만들고 충돌 시 덮어쓰지 않는다. 업로드 후 내려받은 파일의 SHA-256을 비교한다. 이 경로는 모의 전송 검사만 통과했으며 실제 서비스 업로드 성공은 아니다.
- 앱에서 목표에 귀속된 파일만 인증·인증서 고정 TLS로 내려받고 해시를 검사한다. 읽기 전용 ContentProvider로 선택한 문서 앱에 파일 읽기 권한을 전달한다.

## 실제 검증

1. Outlook의 UIRP 안내/신청 DOCX와 L시리즈 메일/기제출 HWPX를 실제 조회·다운로드했다. 개인 문서와 메일은 로컬에 보관했다.
2. 앱의 실제 네이티브 채팅 입력창에서 L시리즈 10월 지원요청서 작성 지시를 넣고 전송했다. 실제 `Qwen3.8-27B-abliterated-AWQ-W4A16`이 구조화된 계획을 반환했다.
3. DOCX/HWPX 생성, 원화와 달러의 별도 합계, 근거 누락 상태, 목표 DB의 채팅/요약/문서 메타데이터 저장을 확인했다. 실제 업로드는 0건이다.
4. 실제 앱 버튼으로 DOCX를 내려받아 기기 저장 파일과 호스트 파일의 SHA-256 일치를 확인했다. ReadEra의 문서 제목과 2쪽 페이지 상태를 확인했다. 전체 페이지 배치/서체/잘림의 시각 검수 완료를 뜻하지 않는다.
5. 실제 Qwen이 만든 UIRP 계획은 템플릿의 Heading 스타일 부재로 초기 렌더에 실패했다. 템플릿에 없는 스타일을 요구하지 않게 수정하고 저장된 실제 모델 계획으로 재생성했다. 이 초기 재생 시험과 별도로 수정 후 앱 채팅에서 실제 Qwen 도구 호출부터 공식 6개 표를 유지한 DOCX/HWPX 생성·목표 저장까지 다시 통과했다. UIRP도 자료가 부족해 needs_information 초안 상태이며 제출 성공이 아니다.
6. 초기 L시리즈 계획에서 모델이 단가/수량을 근거 없는 문자열로 반환해 실패했다. 구조화된 tool-call 스키마를 강제하고 잘못된 필드 타입 검사 및 재발 검사를 추가한 뒤 실제 앱 생성 시험이 통과했다.

## 자동 검사

- 문서 검산·근거·형식·통화·계좌·업로드/해시/잘못된 모델 구조 등 14개 테스트 통과.
- 문서 subprocess 라우팅·파일 소유권·경로 이탈·해시 변조 검사 통과. 모의 Qwen 실행기다.
- 기존 작업 중복/취소/경계 검사 12개 통과. 모의 실행기다.
- 실기기 DB/채팅/문서 분리 등 48개 검사 통과. 문서 결과 상태 저장 검사 3개를 추가했다.
- 정적 검사 3종 통과. 로컬 APK와 설치 APK 해시 일치.

## 계속 필요한 작업
