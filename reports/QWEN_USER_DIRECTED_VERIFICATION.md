## 판정

후속 재시도에서 실제 사용자 지시 → Qwen 도구 선택 → 태블릿 탐색 → 목표별 저장을 확인했다. 같은 fitness 목표에서 영상 전용 지시에는 YouTube, 쇼핑 전용 지시에는 11번가를 Qwen이 선택했다. 공급자·검색어·순서는 호스트가 강제하지 않았다. 쇼핑의 가격 조건 선택과 저장은 통과했고 영상은 원문 확인과 설명 근거에 미해결 문제가 있다. 기존 네 목표 고정 레시피 성공과 이번 사용자 지시 검증은 구분한다.

## 실행 책임

아즈라엘 → 호스트 `qwen-goal-agent.py` → 기존 Azrael Qwen API 연결 → Qwen tool_calls → stdio MCP → 인증·인증서 고정 HTTPS → 태블릿 전경 WebView.

아즈라엘은 실행 시작과 결과 확인을 맡는다. 실행기는 목표 열기 bootstrap, 도구 전달, 모델 ID·단계 제한 검사를 맡는다. `--task`에서 Qwen은 허용된 도구 안에서 공급자·검색어·순서·후보·요약을 선택한다. 앱 입력을 아즈라엘에 자동 접수하는 기능은 없다. 주 대화 모델 변경이나 태블릿 내 27B 추론도 아니다.

## 변경

`--task`로 사용자 문장을 그대로 전달한다. 고정 검색 범주·순서와 첫 도구 강제를 없애고 복합 레시피 도구를 노출하지 않는다. 기존 `--task` 없는 모드는 유지한다. 추적에 모드·사용자 지시·시각·실행기/MCP 해시를 기록한다. 호스트 변경이므로 설치 APK는 변경하지 않았다.

## API 복구 후 실기기 재시도

HTTP 200과 정확한 요청 모델 ID, `OK` 응답을 먼저 확인했다. 설치 APK는 변경하지 않았다. `--task` 모드의 공급자와 검색어는 Qwen이 선택했으며, 실행기는 최초 목표 열기와 모델이 반환한 도구 호출 전달을 수행했다.

- 영상: 13:51:08–13:51:52 UTC, 모델 호출 7회. Qwen이 YouTube에서 `집에서 맨몸 운동 초보자 따라하기`를 검색해 실제 후보 8개를 관측했다. 후보 인덱스 1을 선택하고 observe를 두 번 시도한 뒤 로딩 중을 명시해 보고서를 저장했다. 쇼핑·모임 검색은 없었다. 선택한 영상은 `맨몸운동 홈트레이닝 시작할 때 강력 추천하는 12가지 초보자 전신운동루틴`이었다.
- 영상 제한: source_observed 응답이 없으므로 원문 페이지 제목 확인은 실패했다. 검색 결과의 제목과 채널만 확인했다. 요약의 “12가지 동작을 순서대로 보여줘 따라하기가 쉽습니다”는 실제로 관측하지 않은 영상 구성에 대한 설명이다. 완료 플래그와 report_saved는 실행·저장 성공만 나타내며, 내용의 근거 충족을 보장하지 않는다. 이 시나리오는 부분 통과다.
