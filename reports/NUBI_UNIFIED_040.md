# 누비 0.4.0 통합

대상: Codex `Aside Mobile 프로젝트 검증 (3)` / `(4)`. 각 대화의 완료 보고와 현재 공용 소스를 대조했다. 별도 패키지를 합쳐 설치하는 대신 최신 `ai.decisionos.nubi.travelpilot.goals`를 업데이트한다. 기존 시험 앱은 삭제하지 않는다.

## 합친 범위

- (3): 캠퍼스 도구, 학사일정, 학교 공지, 포털·메일 WebView, 지도·코레일 진입, 생활 계획·할 일·관심 앱·로컬 모델·이벤트 수집.
- (4): 목적별 Qwen 채팅, 실제 WebView 도구 실행, 문서 생성·다운로드·ChatGPT 첨부 경로, 누비 친구 초대·제안·수락, 반응형 companion UI, 기존 Assistant/OpenBot/OpenMuse 화면 선택.
- 공통 화면에서 `나의 누비 → 통합 도구`로 연결. 목표 관리 화면에도 동일 진입점 추가.
- `NubiApplication`이 기존 네이티브 도구에 공통 돌아가기 헤더, 흰 배경, 진한 텍스트, 회색 둥근 입력창·버튼을 적용한다. 새로 생성되는 컨트롤에도 적용한다. WebView 내부와 Canvas 캐릭터는 변경하지 않는다. 기존 화면별 폼 배치는 유지한다.
- 최신 manifest에서 빠졌던 이벤트 전용 수집 서비스를 복원. `canRetrieveWindowContent=false`, 직접 활성화, 별도 화면 조작 서비스는 기본판에 추가하지 않는다.

## 데이터와 실행 경계

같은 패키지의 기존 데이터는 업데이트 설치로 보존한다. 다른 패키지의 쿠키·계정·목표, PC MCP의 선택 기록을 자동 이관하지 않는다. (3)의 OpenCLI/MCP 어댑터는 동일 저장소에서 보존하지만 모두 앱 채팅 도구로 노출되는 것은 아니다. 따라서 모든 외부 서비스가 통합 채팅에서 자동 실행된다는 뜻은 아니다.

Qwen/문서/친구 기능은 기존 호스트·서버 연결을 사용한다. 코레일 자동 조회 차단, SharePoint 업로드 대상·권한, 실제 전화·결제, 모든 플랫폼 전용 탐색은 통합으로 해결되지 않는다. 별도 서비스의 로그인 화면과 사이트 자체 스타일은 해당 서비스 소유다.

## 검증

검증 결과와 APK 해시는 로컬 `nubi-unified-release`에 보관한다. 캡처·원본 대화·인증 자료는 저장소에 추가하지 않는다. 통합 전 미커밋 소스는 로컬 tar.gz로 보존했다.

최종 검증 결과:
- 빌드 및 태블릿 업데이트 설치 성공.
- 통합 화면 진입·공통 스타일 29개, 기존 데이터·목표 흐름 62개, 반응형 65개 통과.
- 목표 규칙 90개, 친구 서버 8개, 보안 정적 검사 2종 통과. MCP 서버·portal.js 문법 및 relay Python 컴파일 통과.
- 설치 APK와 로컬 배포 APK SHA256 일치: `81e9c2689cc0c36498e9b34ee1ffcfe44613f5950df6152de39473caade7c031`.
- 다른 패키지는 버전 목록만 조사했고 데이터·세션을 변경하거나 제거하지 않았다.
- 최신 통합 설치본에서 앱 입력 → Qwen YouTube 검색 → 실제 후보 8개 읽기 → 원문 선택·제목 확인 → 출처 포함 답변 저장 성공. 영상 본문 내용은 분석하지 않았다. 실행 결과는 로컬 `qwen-chat-check.txt`.

공통 헤더의 상태 표시줄 중첩을 실화면에서 발견해 inset 처리를 추가했고, 수정본의 29개 통합 검사를 재통과했다. 기존 62·65 검사 및 Qwen 탐색은 이 inset 수정 직전 동일 기능 소스에서 통과한 기록이다.
